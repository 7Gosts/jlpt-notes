# 日语学习笔记

这个项目用于沉淀日语学习过程中遇到的词汇、语法、动词变形、句子解析和文化表达，便于平时查阅与考前复习。

## 笔记文件

- `日语学习笔记.out`：Fractal Note 大纲和脑图数据，是本项目的主笔记。
- `README.md`：项目说明。
- `AGENTS.md`：约定 AI Agent 如何维护笔记。

## 查看方法

1. 在 VS Code 中安装 **Fractal Note** 扩展（扩展 ID：`imaken.fractal`）。
2. 打开 `日语学习笔记.out`。
3. 根据需要切换 Outliner 或 Mindmap 视图。

## 内容分类

- 词汇
- 语法
- 动词变形
- 句子解析
- 文化与趣味表达

## 记录原则

- 日语条目尽量附带读音和自然中文释义。
- 语法条目包含接续方式、作用、语气和例句。
- 句子解析优先记录原句、读音、翻译和核心语法。
- 将容易混淆、容易读错的内容明确标记。
- 新内容优先归入已有分类，避免重复节点。
