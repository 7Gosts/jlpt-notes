# 日语注音

采用本项目用户确认的效果：原文连续排列，小号浅色假名居中位于对应汉字上方，假名与汉字作为整体换行。用户当次另有要求时，以当次要求为准。

## 渲染与模板

1. 当前环境提供 `visualize` 技能时，读取该技能并按其约定在对话内呈现 HTML 片段。普通 Markdown 不渲染 ruby，不代表内嵌渲染不可用。
2. 读取 [注音模板](assets/japanese-furigana.html)。模板使用内嵌渲染环境提供的字号和主题颜色，不能把未经包装的片段当作独立网页。为本次回答在该环境允许的输出目录创建独立片段，不覆盖模板或前一次回答。
3. 手动填写原句、读音和语义分组，替换根元素及 CSS 选择器中的唯一 ID；保留模板的字体、字号层级、主题颜色和对齐方式。不依赖注音生成脚本或外部接口。
4. 最终回答使用 `visualize` 规定的内容引用直接呈现结果，不输出 HTML 源码、文件下载链接或排版操作说明。

## 注音与排版

- 只给汉字部分注音，已写成假名的部分不重复。例如：今日对应きょう，留守对应るす，団子对应だんご；食べる只在食上方标た，申し訳分别为申标もう、訳标わけ。
- 根据上下文判断读音。无法确认的人名或地名保留原文、暂不注音，并在结果后简短说明；不把猜测的读音标成确定答案。复用用户已确认的读音。
- 每组读音与汉字放在同一个 `.annotated-word` 中，上下排列、水平居中。假名用 `text-small text-muted`，原文用正常字号和正文颜色；不用空格定位注音。
- 保留原句文字及标点，不为对齐而插入空格或改写句子。背景透明，不加标题、边框、按钮或“假名／原文”标签，不另列整句全假名。
- 用 `.phrase` 按语义分组，允许在组间自然换行。分组应足够短以适应窄屏，不能把整段强制放在一行；不要拆散一组注音与汉字，或在动词与助动词之间生硬截断。

## 输出检查

- 核对原文是否完整、读音是否正确，以及每组注音与汉字的对应关系。
- 核对小号浅色注音、正文基线、自然换行和无重叠溢出；改动布局时检查桌面及窄屏效果。
- 确认最终回答引用本次实际生成的片段。只要求注音时，仅呈现结果及必要的读音未确认说明；要求解析时，在注音之后按项目的句子解析规则继续讲解。

仅在用户明确要求纯文本，或当次环境确实没有内嵌渲染能力时，使用 `text` 代码块中的“上行局部假名 + 下行原文”；环境受限时简短说明，不默默切换默认形式。词汇笔记的 `漢字｜かな` 格式不受此 skill 影响。
